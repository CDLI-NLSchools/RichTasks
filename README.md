# CDLI Rich Tasks

A single-file web app presenting a collection of rich tasks for teachers: open
production tasks organized by course, unit and indicator. Every task states its
materials, time and grouping on its face, and each task page offers a printable
student handout that contains the task text only.

## Status

Draft seed version, November 2026. Not yet listed in the CDLI applications
index, pending QA.

## Contents

- `index.html` — the complete app (data, styling and logic in one file, no
  build step and no external assets).

## Seed content

- Fourteen STSE tasks for senior science (Physics 2204 and 3204, Chemistry
  2202 and 3202, Biology 2201 and 3201, Science 1206), authored for CDLI in
  November 2026 and tied to the STSE indicators registered in the Review Apps
  registries.
- Five Mathematics 2201 tasks: three inquiry projects adapted from the
  Academic Mathematics 2201 Curriculum Guide (Department of Education, NL),
  one proportional reasoning task adapted from the Nelson textbook opener, and
  one statistics in the media task adapted from the CDLI course shell.

Every task record credits its source and states whether the text is verbatim,
adapted or original.
